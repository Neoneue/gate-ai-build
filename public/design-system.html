Foundations

Color

Five OKLCH ramps (neutral, blue/brand, success, warning, danger). Neutral is the Tailwind v4 default 11-step ramp (50–950); the four chromatic ramps add a -25 floor step (an extra-subtle wash below 50, used for gradient floors and tinted panel backgrounds), making them 12-step. Color carries state, not hierarchy. Page background is neutral-100, cards are pure white.

Typography

Geist (sans) + Geist Mono. Three semantic families resolve through the type-* utilities: heading (medium, tight/snug), copy (normal weight reading text), label (UI chrome). Weight ceiling is 500 — size and voice carry hierarchy, not bold weights.

Rule

Heading outline

Element level and visual size are independent: the type-* voice sets the look, the tag sets the document outline. Choose the tag for the outline, not the size.

Exactly one <h1> per page — the PageTitle. It is the largest heading and appears once. Section titles are <h2>, card and modal-body titles <h3>. Never skip levels; chrome (sidebar, top bar, wordmark) never emits a competing <h1>.

Motion

Four easing tokens defined in @theme. Defining --ease-* means the bare ease-out utility resolves to the strong curve site-wide. Every transition pairs with motion-reduce fallbacks — the balls below stop under prefers-reduced-motion.

Easing curves

ease-out · default cubic-bezier(0.23, 1, 0.32, 1)
ease-in cubic-bezier(0.4, 0, 1, 1)
ease-in-out cubic-bezier(0.77, 0, 0.175, 1)
ease-drawer · slide-in cubic-bezier(0.32, 0.72, 0, 1)

Durations & patterns

PatternDurationEasing
Button / control press — active:scale-[0.98], will-change-transform 150ms ease-out
Menu item highlight — transition-colors 100ms ease-out
Tabs / Segmented sliding indicator — transform + width 200ms ease-out
Dialog enter — fade + zoom-in-95 200ms ease-out
Sheet / drawer enter — slide from right 300ms ease-drawer
Toast — sonner default (enter / hold / exit) 200ms / 4s / 200ms ease-out
Press affordance is global. The scale-down lives on Button, IconActionButton and TabsTrigger, always paired with motion-reduce:active:scale-100. Popover / select / menu triggers are gated out so they don't scale and cause anchor-reposition flicker.
