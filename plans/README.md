## Findings considered and rejected

Carried forward so nobody re-audits them. The first block is from this session;
the second is inherited from `docs/improve-audit-2026-06-10.md`.

**2026-07-27:**

- `?open=` modal artifacts: not dead code. Reachable from live `navigate()` in
  `Dashboard.tsx:783,835`, and documented as deliberately retained deep-link
  surfaces alongside the full detail pages.
- Fake AWS key at `src/data/requests.ts:871`: detector fixture data, not a
  credential. Worth an allowlist marker only because it may trip secret
  scanners.
- `dangerouslySetInnerHTML` at `src/components/ui/chart.tsx:94`: emits CSS
  custom properties from static developer-authored theme config. No user data.
- Listener/timer cleanup: all 41 sites verified to have add/remove parity. This
  codebase is unusually disciplined here.
- Type escape hatches: zero `@ts-ignore`, `@ts-expect-error`, `as any`, or
  `as unknown as` in `src/`.
- Memoization in the big table pages: already correct (Activity has 10 `useMemo`
  covering the full chain; Conversations, Models, Security likewise).
- `Team.tsx` / `Models.tsx` unsliced pagination: same shape as finding #3, but
  4 members at 10/page and 23 models at 25/page fit one page. Unobservable.
- Naive "consolidate the Free/Default/Pro twins": the twins are an intentional
  product-demo decision. Only unintended drift between them is a finding.
- Separate `typecheck` script: `npm run build` already runs `tsc -b` and CI runs
  build on every PR. Marginal gain.
- `react-router` HIGH advisory: no exploit path in this app (no SSR, all
  `navigate()` arguments are template strings over static mock data). Still
  worth a `npm audit fix` as free hygiene, but not a security finding.

**Inherited from 2026-06-10 (still valid):**

- Activity Recharts re-render: the cited comment documents a fix already
  applied. Auditor misread the fix as the problem.
- Billing `JSON.parse` unguarded: sits in try/catch with per-field type guards.
  By design.
- Draft/applied dual filter state in Requests: deliberate staged-apply modal
  pattern.
- `shadcn` "dead dependency, uninstall": false. `src/index.css:5` imports its
  `tailwind.css`. Was corrected into a move-to-devDependencies fix.
- TypeScript version pin: harmless.
